# Papyrus Desktop v2.0.2

**发布日期**：2026-10-28<br>
**版本类型**：正式版

> **紧急升级通知：所有使用 Papyrus 2.0.2 之前版本的用户，请立即备份并更新到 2.0.2，包括所有历史桌面版本、测试版本，以及已经停止维护的 Python 版本。** 本次为安全维护版本，更新桌面应用实际携带的 Node.js 运行时及存在已知安全通告的依赖。旧版 Python 用户同样需要迁移到受维护的 2.0.2；这项升级要求不代表 Python 运行时本身受到本次 Node.js 漏洞影响。

## 本版重点

- Windows、macOS（Apple Silicon / Intel）和 Linux 安装包统一采用 Electron 43.8.4，内置 Node.js 24.22.1，包含 2026-10-21 Node.js 安全修复。
- 更新网络请求、输入校验、图片处理、Markdown 和 HTML 净化等依赖及其 lockfile。
- 保留 macOS 12 最低系统要求，并继续使用各平台实际打包的 Electron 二进制执行运行时与后端启动检查。
- 根目录、前端、后端及三个 lockfile 的版本统一为 2.0.2。

## 新增功能

本版本无此类变化。

## 体验改进

- 在更新校验库后保持现有自动化行为：只修改任务名称等局部字段时，已暂停的任务继续保持暂停。
- 同步更新兼容范围内的前端与构建依赖。

## 安全与稳定性

- 升级 Electron 内置 Node.js 至 24.22.1，包含 Brotli 解码越界写入（CVE-2026-111497）、DNS 含 NUL 字符处理及 TLS 主机名校验等修复。安全修复位于安装包运行时；仅升级系统 Node.js 无法修复已安装的旧桌面应用。
- 更新 Fastify 5.12.7、Undici 8.12.3、Sharp 0.35.5、Markdown-it 14.3.3、DOMPurify 3.4.17 等依赖，修复对应上游安全通告涉及的问题。
- 升级 Zod 4.6.7 与兼容的 OpenAI SDK 7.45.1，适配校验错误与字典类型接口，保留现有出站请求 SSRF 防护、本地 Provider 支持和代理策略。
- 本次未新增数据库迁移。升级前仍须备份，首次启动后请检查卡片、笔记、附件与 AI 配置。

参考：[Node.js 安全公告](https://nodejs.org/en/blog/vulnerability/october-2026-security-releases)、[Node.js 24.22.1 修复明细](https://nodejs.org/en/blog/release/v24.22.1)、[Electron 43.8.4 发布说明](https://releases.electronjs.org/release/v43.8.4)。

## 构建与发布

- 构建 Node.js 固定为 24.22.1；Electron 固定为 43.8.4，避免构建依赖范围漂移。
- 提供 Windows x64 NSIS、macOS arm64 / x64 DMG、Linux x64 AppImage / DEB。
- 保留实际安装包运行时门禁：运行应用自身二进制检查 Node 安全基线，并启动打包后端验证健康状态与应用版本；主机 Node 的检查结果不能代替它。
- 将 Jest 更新至 30.5.2，以支持新版 Fastify 依赖的 ESM 加载，不通过回退安全依赖或跳过测试解决兼容问题。

## 相比上一版本

v2.0.1 主要提供本地 API 鉴权、SSRF、CSP 与错误信息处理等安全加固。v2.0.2 在这些机制基础上更新桌面运行时和依赖安全补丁，重点解决用户安装包中旧 Node.js 运行时的风险，继续保留 macOS 12 支持。

## 使用提示

- **所有旧版用户均应立即更新到 2.0.2，不要继续使用 2.0.1 或更早版本，也不要继续使用已停止维护的 Python 版本。**
- 升级前退出 Papyrus，备份完整用户数据目录（默认 `~/PapyrusData`；使用自定义目录的请备份实际目录）及旧版 Python 数据。请保留原始数据，完成迁移并确认记录完整后再处理旧版程序。
- Python 版不会再获得后续安全补丁。旧数据格式可能不同，请核对导入与迁移结果；本公告不承诺所有历史格式都可直接覆盖升级。
- 桌面版请安装匹配操作系统与 CPU 架构的附件，首次启动后确认版本显示为 2.0.2，并检查 AI Provider、复习队列和附件是否正常。
- macOS 最低为 12；安装包的系统信任提示与代码签名状态以实际产物为准。
