# Papyrus v2.0.0-beta.11 Release Notes

> **版本**: 2.0.0-beta.11
> **发布日期**: 2026-06-16
> **分支**: `codex/BA11-release`
> **基线**: `main` (v2.0.0-beta.10)

---

## 🚀 重大更新

### 全新前端 UI 全面重构
- **彻底移除旧版 UI**，从零构建现代化的多栏布局界面
- 新增**副侧边栏**、可拖动**聊天栏**、**状态栏**、**顶部标题栏**等组件
- 优化全局边距、模式选择颜色、侧边栏交互体验
- AI 输出框新增**模型 ID 显示**，便于识别当前调用模型

### 卷轴学习系统 (ScrollPage)
- 构建完整的**卷轴复习界面**（ScrollPage），支持高强度闪卡学习
- 优化卷轴学习交互体验，支持键盘驱动的心流复习
- 窗景系统接入卷轴界面，提供沉浸式学习背景

### 开始界面 (StartPage)
- 完成全新的**开始界面**，集成今日概览、复习队列、节气主题
- 添加**菜单界面**、**基础设置界面**、**数据界面**
- 支持窗景按钮交互与动画效果

### 笔记系统升级
- 新增**笔记查看器**（Markdown 渲染）
- 后端引入 **Obsidian Vault 导入** 功能（chokidar 文件监听）
- 支持 **Note 标签** 管理与文件夹层级
- 笔记关系图（RelationGraph）基础架构

### 文件库与扩展管理
- 文件库页面新增**窗景支持**
- 扩展管理页面新增**窗景支持**
- 数据界面加入窗景背景

---

## 🎨 窗景系统 (Scenery)

- 构建完整的**窗景系统**，支持各页面背景渲染
- 优化窗景动画与透明度设置
- 修复背景渲染 bug，调整透明度范围与实际一致
- 修复窗景按钮**定位错位问题**
- 窗景支持：开始页、卷轴页、数据页、文件库、扩展管理

---

## ♿ 无障碍支持 (a11y)

- 添加**无障碍支持**（WCAG 2.1 AA 覆盖，AAA 对比度方案）
- 添加**无障碍文档**与使用说明
- 调整全局**字重**（font-weight）规范，修复开始页、设置页字重不对的问题
- 使用 CSS 变量统一管理字体字重，调整标题层级关系
- 统一卡片样式，优化屏幕阅读器兼容
- 减少动画模式支持

---

## 🤖 AI 聊天系统增强

- **多会话支持**：聊天面板支持多会话切换、附件、会话重命名
- **AI 配置迁移**：从 JSON 文件迁移至**数据库持久化**（`Migrate AI config from JSON file to DB`）
- **持久化 UI 状态**：聊天面板侧边位置与 UI 开关状态持久化
- **模型选择器重构**：将模型选择器移入 `ChatToolbar`，优化交互
- **Agent 模式优化**：去除 Agent 模式在未拉起状态下的文本显示，避免干扰
- 全局添加**字号变量**与组件尺寸系统

---

## 🛠️ 设置系统

- 构建**基础设置界面**，支持：AI 配置、外观、快捷键、无障碍
- 设置接入**窗景功能**与窗景配置
- 重写设置内容结构，更换悬停显示方式
- 支持日期格式设置（真正生效）
- 透明度设置修复与范围调整

---

## 🌍 国际化 (i18n)

- 新增 **i18n 多语言支持**框架
- 支持四种语言：简体中文（zh-CN）、英文（en-US）、繁体中文（zh-TW）、日文（ja-JP）
- 语言包位于 `frontend/src/locales/`
- 默认语言为简体中文
